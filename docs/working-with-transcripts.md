# Работа с транскриптами через агента

Когда капсула покажет, что текст готов, можно попросить агента сделать саммари,
найти договорённости или проверить, что обсудили из агенды. Повторно
распознавать звук не нужно: агент читает `*.sources.transcript.txt` и, если есть,
сохранённый контекст встречи `*.context.json`.

## Установка скила

В репозитории есть переносимая папка
[`skills/local-audio-transcriber`](../skills/local-audio-transcriber/SKILL.md).
Скопируй её в каталог скилов своего агента. Например, для Codex:

```bash
mkdir -p ~/.codex/skills
cp -R skills/local-audio-transcriber ~/.codex/skills/
```

Если скил с таким именем уже установлен, сначала сравни версии.
Для другого агента используй его каталог скилов. Если он не поддерживает
`SKILL.md`, передай этот файл как инструкцию вместе с транскриптом.
Для автоматического поиска последней записи нужен `python3` (только стандартная
библиотека). Копируй папку целиком, включая `scripts/`. Для работы с явно указанным
транскриптом Python не нужен. Модели и календарный MCP не обязательны.

Агенту нужен доступ к папке записей. На Mac он может прочитать настройку
Meeting Companion; стандартная папка — `~/Downloads/Meetings/YYYY-MM/DD/NAME/`.
Если агент работает на другой машине, передай ему нужный транскрипт и,
при необходимости, `context.json` либо укажи доступную папку.

## Примеры запросов

**Саммари последней встречи:**

> Используй local-audio-transcriber. Найди последнюю запись Meeting Companion
> и кратко подведи итог: что обсудили, что решили, какие вопросы остались.

**Договорённости с сохранением рядом с записью:**

> Из последней встречи собери действия, ответственных и сроки.
> Неизвестные сроки не придумывай. Сохрани результат в summary.md рядом
> с транскриптом, с тем же именем записи.

**Проверка по агенде:**

> Сверь последнюю встречу с сохранённой агендой. Что обсудили, что пропустили?
> Используй context.json рядом с записью. Если его нет, работай только с транскриптом.

**Уточнение спикеров:**

> Host — это я, Алексей. Speaker 2 — Мария. Подготовь саммари с именами,
> а спорные реплики отметь временными метками для проверки.

**Конкретный файл:**

> Прочитай /путь/к/meeting_2026-10-20_10-00-00.sources.transcript.txt.
> Найди решения по запуску проекта и приведи временные метки.

## Что учитывать

Host — источник микрофона, Remote — системный звук. На обеих дорожках может быть несколько голосов; их соответствие источникам указано в Speaker guide. Имена нужно подтвердить.
Список приглашённых из календаря сам по себе не определяет, кто говорил.
Скил сохраняет саммари только по просьбе и не меняет исходный текст.

Распознавание в Meeting Companion локальное. Облачный агент получает текст,
который ты ему передаёшь или разрешаешь прочитать. Учитывай правила своей
команды для записей и персональных данных. Календарь необязателен.

Новые записи лежат в `YYYY-MM/DD/NAME/`: итоговый текст, контекст и общая M4A — в папке встречи; дорожки, промежуточные транскрипты и лог — в `raw/`. Старые записи могут лежать прямо в папке дня.
