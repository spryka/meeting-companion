# beta.40: ускорение обработки и короткие реплики

Версия 2.0.0-beta.40/build78 опубликована 2026-11-11 и объединяет локальные
beta.37–beta.39. Ниже сохранены результаты проверки этой версии.

## Изменения

- Cascade использует индексы интервалов и кеширование нормализации; правила
  выбора кандидатов, порядок и журнал сохранены.
- Gate использует уже вычисленные интервалы Nemotron каждой дорожки. Строгое
  пересечение допускает прежнее целое окно 25 с с шагом 24 с без min250ms/padding.
  GigaAM и Parakeet получают одну маску, исходные samples и прежнюю шкалу времени.
- Missing/failed/empty diarization допускает все окна соответствующей дорожки.
  Предупреждения и отмена сохраняются. Отдельный Silero inference исключён;
  его файлы не требуются при подготовке и не удаляются из существующего cache.
- Подпись этапа — «Nemotron (отбор окон)»; маршрут и progress protocol прежние.
  Старые результаты и ручные правки не перерабатываются автоматически.

## Проверки

Production код и тесты совпадают с проверенной и установленной beta.39.
Для неё прошли release build, 569 Swift Testing и 13 XCTest при
swift test --no-parallel, Python-free, module boundaries, finder self-test,
strict OpenSpec validation и signed bundle check. Новых изменений inference
при выпуске beta.40 нет; меняются release metadata, документы и лента обновлений.

На четырёх реальных записях (в сумме около 122 минут) packaged worker beta.39
точно совпал с исследовательским Nemotron gate по 9 смысловым полям JSON,
всем 40 815 строкам ordered correction journals и нормализованному playback path.
Исходные WAV-хеши сохранились. Packaged check/prepare прошли без Silero и с
повреждённым неиспользуемым Silero cache; исходные модели не менялись.

Прослушивание контрольных записей подтвердило четыре новые реплики: «Нет.», «Да.», «Пока.»
и «Ну, сейчас запустил.». Последняя распознана как «запустим» — эта ошибка ASR
остаётся. Новые слова могут менять grouping/timestamps существующего cascade
в других фрагментах; exact parity с прежним Silero gate не заявляется.

Исследовательский A/B: 197.888→144.955 с на одной часовой записи после ускорения
cascade; 318.911→266.092 с суммарно на четырёх записях при переходе на Nemotron gate.
Это разные эксперименты; проценты не складываются. Второй — по одной паре на каждую
запись, без отдельного прогрева. Стабильный выигрыш и экономия RSS не установлены.

Независимые review: контракт Nemotron gate PASS (ремонт 1/2 для подписи UI),
production integration и install evidence PASS (product repairs 0/2).
Установка beta.39 сохранила 222 файла, включая последние ручные правки.

## Границы приёмки

Physical capture/микрофон/permissions UAT и About UI не выполнялись; версия
установленной beta.39 подтверждена metadata, библиотека и готовый текст открывались.
В обычном конкурентном suite ранее дважды превышался существующий W08 timing limit;
последовательный полный suite прошёл без изменения теста. Общая WER/точность,
другие записи и стабильный RSS не проверены. Apple notarization отсутствует.
Эти ограничения не выдаются за выполненные проверки или гарантии качества.

Основные specs синхронизированы с реализацией. Ручная проверка реальной записи
с микрофоном, системным звуком и готовым транскриптом завершена на beta.41
2026-11-12; change `nemotron-speech-gate` архивирован при подготовке 2.0.0.
Результаты выше относятся к beta.39–beta.40, а не к повторному benchmark 2.0.0.
