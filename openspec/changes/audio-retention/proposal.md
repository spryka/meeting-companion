# Why

Аудио остаётся на диске после завершения встречи. Пользователь может освободить место по сроку хранения, сохранив результаты встречи в библиотеке.

## What Changes

- В настройках записи появляется очистка аудио по сроку с начальным значением 14 суток
- Правило действует после включения для выбранной папки и охватывает старые записи, в том числе с незавершённой обработкой
- Приложение и обработчик убирают осиротевшие временные копии после аварии обработчика

## Capabilities

### New Capabilities

- `audio-retention` — очистка аудио встреч по сроку хранения

## Impact

Настройки записи, библиотека и чтение аудио.
