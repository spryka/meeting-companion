# Проверка эксперимента

## До реализации

Подготовка: `test_preparation_selects_mlx_vad_and_q8_parakeet` падает assertion:
прежняя подготовка выбирает ONNX Silero вместо MLX. Ошибок окружения нет.
Проверки новых API первоначально падали из-за отсутствующих методов;
это не считается поведенческим RED. Исследовательская загрузка моделей
выполнена отдельно до включения в продукт.

## Первые проверки

- Parakeet Q8: strict-загрузка, инференс и пустой результат на тишине проходят.
- Silero v5: пропускает окно с короткой репликой; вариант отклонён.
- Silero v6: сохраняет это окно; два отличия масок на шести дорожках относятся
  к окнам без слов в прежнем результате GigaAM. Это не ручная оценка речи.
- Тесты покрывают усиленную копию, границы окон, пустой вход, объединение
  субслов, порядок/границы таймкодов, маску Parakeet и прогресс.

## Ограничения

Подробные измерения и пользовательские данные находятся вне репозитория.
Изменение текста относительно прежней модели не является WER без эталона.
UAT на новых встречах, тихая речь и работа без сети в установленном приложении
требуют отдельной проверки. Подготовка чистого кэша приложения не подменяется
экспериментальным кэшем.

## Сравнение на реальных дорожках

Три фрагмента по пять минут, host и remote, по три последовательных запуска
каждого варианта (18 обработок встреч). GigaAM в обеих группах — al-bo MLX.
Сравниваются прежние ONNX VAD + GGUF Parakeet и MLX VAD v6 + Q8 Parakeet.

| Фрагмент | Прежний конвейер, медиана с | Полный MLX, медиана с |
|---|---:|---:|
| A | 19.79 | 18.91 |
| B | 22.44 | 21.48 |
| C | 17.68 | 17.42 |

1503 исходных слова GigaAM с таймкодами и голосами совпали точно.
Три локальных различия итогового текста приходятся на коррекцию Parakeet.
Каждый вариант детерминирован на трёх прогонах, предупреждений нет.
Ручной эталон не составлялся; WER и улучшение качества не заявляются.

Peak RSS: прежний 1064–1625 MiB, MLX 1079–1588 MiB. MLX peak:
1929 MiB и 2679 MiB соответственно; прежний счётчик MLX не включает память
GGUF/Metal. Эти показатели не складываются и не доказывают экономию общей памяти.

Дополнительные проверки реальными моделями: минутная тишина не создаёт
речевых окон; речь на границах окон сохраняется при исходной амплитуде,
ослаблении до 25% и 5%; Parakeet на тишине 1 и 25 секунд не выдаёт слов.

Python: 83 tests, 82 passed, 1 skipped (опциональный нативный AEC helper).
Release-сборка и проверка подписи bundle проходят; linker сообщает прежние
предупреждения о несуществующих путях CommandLineTools.
Офлайн-диагностика всех четырёх моделей из bundle проходит в окружении
без onnxruntime, onnx_asr, transcribe_cpp, torch и sentencepiece.

## Упаковка и установка

Изолированная подготовка с новым Python/cache установила 36 пакетов,
затем прошла офлайн-диагностику. Для неё использован уже подготовленный
экспериментальный snapshot моделей; это не проверка чистой загрузки моделей.
Полный офлайн-прогон двух дорожек из bundle без sentencepiece совпал
по обоим correction journals с результатом сравнения; исходное аудио сохранено.
Установлена 1.7.3-beta.2 (38) с прежней подписью. SHA-256 установленных
скриптов совпадает с worktree, codesign --verify --deep --strict проходит.
UI показывает версию beta.2 и обычное предложение подготовки; загрузка
из пустого app-owned cache запущена через кнопку приложения.

Подготовка установленного приложения с пустыми собственными models/runtime
завершилась успешно: Python, 36 пакетов и все четыре snapshot скачаны обычной
кнопкой UI. Диагностика всех моделей прошла, предложение подготовки исчезло,
кнопка «Начать запись» активна. Экспериментальный кэш в app-owned cache
не копировался. Новая запись и живой UAT в этой версии ещё не выполнялись.
