# Дизайн

В существующем изолированном worktree заменяем VAD и Parakeet, сохраняя GigaAM
al-bo и Nemotron. В приложении нет скрытого запуска двух бэкендов.
Прежние скрипты сохраняются вне репозитория только для сравнения.

Silero получает отдельную усиленную копию. Порог 0.5, минимум речи 250 ms,
тишины 250 ms, padding 150 ms. MLX API не ограничивает интервал речи 20 секундами;
для бинарной маски пересечения целых ASR-окон это оценивается сравнением масок.
Интервалы остаются в сэмплах исходной шкалы.

Parakeet Q8 сохраняет float16 для неквантизованных слоёв. Инференс получает
float16; токены объединяются по пробелам с сохранением начала первого и конца
последнего токена. Проверки конечности, порядка и границ выполняются до
отбора слов по прежним швам окон 25/24 секунды.

Модели читаются только из закреплённых локальных snapshot, strict=True.
Подготовка скачивает их явно. Убираем onnx-asr, onnxruntime, transcribe-cpp;
GigaAM использует свой декодер без пакета sentencepiece. Нативный AEC остаётся DSP.

Сравнение: одинаковые копии дорожек, последовательные процессы, прогрев и три
замера. Отдельно текст GigaAM, донорские слова, замены каскада, VAD-маски,
таймкоды, wall time, peak RSS и MLX peak (не складываются).
Без ручного эталона расхождение текста не называется WER.

Проверка v5 выявила потерю окна с короткой репликой. Для UAT выбран v6.
В mlx-audio 0.5.8 класс создаёт ветки 16 и 8 kHz; закреплённая v6 содержит
только 16 kHz. Перед строгой загрузкой исключаем неиспользуемую ветку 8 kHz.
Приложение принимает только 16 kHz; неполные веса рабочей ветки не допускаются.

Для перехода со старой версии состояние готовности начинается с false.
Стартовая проверка использует --availability: текущие snapshot и окружение
проверяются офлайн, без инференса. Сохранённый флаг transcriptionPrepared больше
не читается и не обновляется. Новые веса скачиваются только явно; старые
модели и окружения сохраняются до пользовательского сброса всего кэша.
