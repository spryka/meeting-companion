## ADDED Requirements

### Requirement: Single MLX neural runtime trial
Система SHALL выполнять GigaAM, Nemotron, Silero и необязательный Parakeet
через MLX, без ONNX Runtime и transcribe-cpp в зависимостях приложения.

#### Scenario: Offline inference
- **WHEN** пользователь подготовил модели и отключил сеть
- **THEN** диагностика и распознавание с Parakeet используют локальные закреплённые веса

### Requirement: Preserve source timeline and baseline
Система SHALL сохранять исходные аудио, сетку ASR 25/24 секунды,
абсолютные таймкоды и исходный текст GigaAM при коррекции Parakeet.

#### Scenario: VAD boundary speech
- **WHEN** речь пересекает два соседних окна
- **THEN** оба окна допускаются к распознаванию без сдвига времени
- **AND** усиление применяется только к копии для VAD

#### Scenario: Parakeet subword alignment
- **WHEN** слово состоит из нескольких токенов Parakeet
- **THEN** каскад получает целое слово с началом первого и концом последнего токена
- **AND** нечисловые, неупорядоченные или выходящие за границы таймкоды вызывают предупреждение с сохранением GigaAM

### Requirement: Validate readiness after upgrade
Система SHALL проверять наличие актуальных закреплённых моделей и Python-окружения
при каждом запуске без сетевых запросов и загрузки моделей в GPU.
Сохранённый предыдущей версией статус готовности SHALL не заменять проверку.

#### Scenario: Only legacy models are cached
- **GIVEN** предыдущая версия сохранила успешную подготовку
- **WHEN** пользователь запускает обновлённое приложение без новых MLX-весов
- **THEN** на экране записи предлагается скачать модели
- **AND** старые модели, окружения и записи не удаляются автоматически

#### Scenario: Current snapshots already exist
- **WHEN** текущие модели и окружение доступны офлайн
- **THEN** приложение становится готово к транскрибации без повторной загрузки
