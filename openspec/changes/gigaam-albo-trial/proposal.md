# Proposal

## Why

Проверить GigaAM v3 E2E RNNT MLX от al-bo в обычной работе приложения перед заменой ONNX. На сохранённых фрагментах текст и таймкоды совпали с ONNX; нужен пользовательский UAT.

## What Changes

- В тестовой сборке GigaAM по умолчанию использует al-bo MLX с FP32 при исполнении.
- Runtime и декодер включаются в приложение; веса скачиваются штатной подготовкой.
- Диагностика и офлайн-режим проверяют новые веса. ONNX остаётся доступным для технического сравнения до завершения UAT.

## Capabilities

### New Capabilities

- `local-asr`: подготовка и выполнение MLX ASR с таймкодами токенов.

### Modified Capabilities

Нет.

## Impact

Python ASR, подготовка моделей, упаковка и лицензии. Захват звука, диаризация, VAD, AEC, Parakeet и формат слов не меняются. Публикация стабильного релиза зависит от UAT. Снижение общего расхода памяти для FP32 не заявляется.

Уточнение для release/1.7.3: следующий change `full-mlx-trial` исключает
ONNX-бэкенд и переменную выбора из приложения. Прежний конвейер остаётся
только во внешнем стенде сравнения. Текущий состав описан в docs/transcription-pipeline.md.
