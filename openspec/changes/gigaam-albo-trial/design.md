# Design

Runtime misteral/GigaAM из коммита b258565b39bbf7912cad6c61d70bc1d9491ad156 включается как отдельный Python-модуль с MIT notice. Адаптер сохраняет кадры выдачи токенов; шаг берётся из конфигурации. Сборка слов и обработка перекрытий остаются прежними.

Веса al-bo/gigaam-v3-e2e-rnnt-mlx закреплены на 9488b39159c6d30f0fbaef1e41459f1e078daf30. Файлы model.safetensors, config.json и tokenizer.model проверяются существующим model_assets. FP16-файл разворачивается в FP32 при загрузке, как в проверенном upstream режиме.

Штатная подготовка получает новые веса; кэш ONNX сохраняется. Переменная MC_GIGAAM_BACKEND=onnx остаётся только для сравнения и выбирает отдельную закреплённую модель. Автоматического переключения при ошибке нет. Конечному пользователю переменные и установка пакетов не нужны.

Проверки: RED выбора MLX по умолчанию и нового модельного контракта; GREEN синтетических тестов; штатная подготовка и офлайн-диагностика из подписанного bundle; повторное сравнение на копиях записи. UAT: запись встречи, прогресс, результат и повторный запуск без сети. Без UAT change не архивируется.

Уточнение для release/1.7.3: следующий change `full-mlx-trial` исключает
ONNX-бэкенд и переменную выбора из приложения. Прежний конвейер остаётся
только во внешнем стенде сравнения. Текущий состав описан в docs/transcription-pipeline.md.
