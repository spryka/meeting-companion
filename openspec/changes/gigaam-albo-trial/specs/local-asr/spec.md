## ADDED Requirements

### Requirement: Prepared local MLX recognition
Система SHALL автоматически подготавливать закреплённые веса al-bo и использовать включённый в приложение runtime для распознавания в тестовой сборке без ручной установки пакетов.

#### Scenario: First preparation
- **WHEN** пользователь подготавливает модели в тестовой сборке
- **THEN** скачиваются закреплённые файлы MLX ASR
- **AND** существующие записи и кэш ONNX сохраняются

#### Scenario: Offline recognition
- **WHEN** пакеты и модели подготовлены и сеть недоступна
- **THEN** распознавание выполняется без сетевых запросов
- **AND** возвращает упорядоченные таймкоды токенов для прежней сборки слов

#### Scenario: Missing offline model
- **WHEN** нужных весов нет в кэше и включён офлайн-режим
- **THEN** диагностика сообщает о необходимости подготовки
- **AND** система не переключается на другой движок молча
