## Why

В длинной встрече новый голос может впервые появиться в конце. Сегодня для назначения имени нужно найти его реплику в полном транскрипте. Это замедляет разбор и не даёт увидеть, какие голоса ещё требуют внимания.

## What Changes

- Добавить вход через количество говорящих в шапке текущего транскрипта.
- Показать список всех исходных голосов и все реплики выбранного голоса с прослушиванием фрагментов.
- Назначать имя группе за всю встречу с сохранением ручных назначений по умолчанию и явной возможностью их заменить.
- Сохранить быструю правку имени у реплики: только эта реплика либо тот же голос отсюда до конца. Добавить переход из неё к общему разбору выбранного голоса.
- Убирать из календарных подсказок имена, уже назначенные любой реплике текущего результата. Ручной ввод сохраняется.
- Сохранить полное окружение workspace и адаптацию к узкой ширине.

Автоопределение людей, voice embeddings, объединение голосов, отдельное хранилище профилей, saved undo, установка и выпуск не входят в изменение.

## Capabilities

### New Capabilities

- `speaker-review`: полный разбор исходных голосов текущего результата.

### Modified Capabilities

- `transcript-review`: точечное назначение сохраняется; добавляются переход к полному голосу и фильтрация календарных подсказок.
- `desktop-workspace`: уточнение W04 для двух входов и общих правил подсказок; остальные существующие сценарии W04 сохранены целиком.

## Impact

Native SwiftUI/AppKit presentation и состояние TranscriptReviewWindowModel; существующие Core assignment/session/edits и playback. Хранение result.json/edits.json, границы модулей, запись аудио, worker и календарь не мигрируют. Новый UI использует текущую session, а не создаёт независимый редактор.
