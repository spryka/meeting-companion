## Context

Production beta.38 использует Nemotron, затем отдельный compiled Silero. Четыре исследовательские пары дали 360→364 допущенных окна, ни одного удалённого, время 318.911→266.092 s. Владелец подтвердил речь во всех четырёх добавленных окнах; «запустим» вместо «запустил» остаётся ошибкой ASR. Это ограниченная выборка, по одной паре без отдельного прогрева.

## Goals / Non-Goals

**Goals:** перенести исследованный gate, проверить полный packaged worker и безопасно установить beta.39.
**Non-Goals:** новый ASR, настройки выбора gate, очистка Silero cache/vendor, смена capture/AEC/JSON, публичный релиз, обещание универсального ускорения.

## Decisions

- Общий чистый helper PipelineLogic принимает frameCount, интервалы и статус диаризации. Строгое пересечение вычисляется в Double seconds, как в исследованном candidate; перевод интервалов в целые samples мог бы изменить границы.
- При status != completed или пустых интервалах допускать все окна. Production уже считает пустой результат failed. Это сохраняет исследованный fail-open путь; тишина при пустой диаризации может стоить полного ASR, но полнота приоритетна.
- Runner заменяет только Stage 2, проверяет cancellation до каждой дорожки, сохраняет masks для обоих ASR. Station vad сообщает completed или skipped; wire protocol, station IDs и маршрут не меняются; подпись модели в подробностях меняется с Silero speech gate на Nemotron (отбор окон). Усиление detection copy больше не требуется.
- Исключить vadSpec из двух списков обязательных моделей ModelAssets; manifest/vendor/BoundedVAD оставить для существующих тестов и исторического воспроизведения. Не требовать неиспользуемую модель и не удалять её кеш. Альтернатива сохранять обязательную подготовку добавляла бы ненужные загрузки.
- ADR0001/0003 действуют с частичными supersessions ADR0004, ADR0004 с ADR0005, ADR0006 с ADR0007; ADR0002 сохраняет worker/model ownership. Нового долговременного архитектурного решения нет.

## Risks / Trade-offs

- Другая запись может получить другую маску → проверить границы/failure и полный продукт на четырёх сохранённых контрольных входах; общая WER не установлена.
- Новые слова могут менять cascade grouping/timestamps вне новых окон → не обещать exact parity с beta.38; сравнивать с исследованным B, сохранять исходный GigaAM и старые результаты.
- Нет стабильного RSS/скоростного вывода → полные прогоны здесь проверяют интеграцию, не универсальный benchmark.

## Migration Plan

Без миграции данных. Регрессионный red/green, release build, последовательный полный suite, project checks, подписанная упаковка и четыре full-worker сравнения с research B. Независимое review до установки. Свежая проверка idle, normal quit, install-app.sh с прежней подписью, About/library и инвентарь данных до/после. Возврат прежнего bundle не меняет записи. Новая beta не перераспознаёт старые записи автоматически.

## Open Questions

Нет блокирующих решений. Полная ручная разметка/WER и physical capture UAT не входят в проверенную область; установка не объявляет их выполненными.
