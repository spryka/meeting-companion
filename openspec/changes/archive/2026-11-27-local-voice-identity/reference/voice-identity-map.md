# Голоса — единый редактор имён

[Транскрипт](index.html) · [Единый редактор](index.html?scenario=editor) · [Все знакомы](index.html?scenario=all-known) · [Настройки → Голоса](index.html?scenario=voices) · [Первое включение](index.html?scenario=empty)

## Целевой путь

Записать встречу → получить транскрипт с именами знакомых людей → при необходимости вручную разобрать новые и неуверенно распознанные голоса. Сопоставление выполняется один раз при обработке нового результата. Открытие готовой записи показывает сохранённые имена.

## Один редактор, два входа

| Вход | Что открывается |
| --- | --- |
| Имя у реплики в транскрипте | Единый редактор в правой области, сразу выбрана эта реплика |
| «N говорящих» в шапке | Тот же редактор со списком групп голосов; сохраняется последний выбранный фрагмент этой встречи |
| «Разобрать неопознанных» | Тот же редактор с фильтром групп, содержащих реплики без имени |
| Имя у фрагмента внутри редактора | Та же форма для выбранной реплики; без второй модалки |

Отдельная модалка «Сменить спикера», её форма и отдельный обработчик сохранения удалены из текущего index.html. Предыдущий speaker-review.html остаётся историческим эталоном и не является действующим входом.

## Фильтр списка голосов

Над списком голосов доступны два сегмента со счётчиками: «Все» и «Неопознанные». В «Неопознанных» остаются группы хотя бы с одной репликой без сохранённого имени. Если текущая группа не подходит под фильтр, выбирается первая подходящая; черновик прежней реплики остаётся для возврата. Сохранение, исключившее активную группу, тоже переводит выбор на первую видимую. Переключение ничего не сохраняет и не обучает.

Когда неподписанных реплик больше нет, показано «Неопознанных голосов нет»; сегмент «Все» остаётся доступен. Счётчики считаются по сохранённым назначениям, а не по черновикам.

## Что видно сразу

- В списке слева сначала имя человека. Робот обозначает автоматическое назначение, перо — ручное. Под именем — дорожка и число реплик.
- Если группа содержит разных людей, показано «Разные имена»; единое имя группе не приписывается.
- Справа — сохранённое имя конкретной реплики, источник назначения, время и текст фрагмента.
- Поле имени заполнено текущим именем. Существующий человек уже выбран по сохранённой идентичности.
- Одноимённых людей различают по email или подписи. В демо есть email. Нативная связь требует однозначного сохранённого участника и явного выбора.
- Под выбранной репликой одно поле имени. При вводе оно ищет сохранённых людей и участников календаря по имени, email или подписи. Список также открывается стрелкой поля. «Другие реплики этого спикера» показывает таймкод и текст каждого фрагмента. Нажатие на текст выбирает реплику, кнопка с таймкодом запускает общий демо-плеер без звука. Причина неопределения доступна под «?».

## Одинаковые последствия действий

| Действие | Результат |
| --- | --- |
| Открыть через любой вход | Только просмотр. Не сохраняет имя и не обучает профиль |
| Оставить автоматическое имя без изменений | Эта реплика не попадает в изменения и не становится ручной разметкой. Имя можно применить к другим репликам того же голоса с машинным происхождением и без обучения |
| Изменить имя или выбрать другого человека | Появляется черновик. Транскрипт обновляется при сохранении |
| Применить имя | Из реплики начальная область одна реплика, из шапки — группа. Существующий черновик сохраняет выбранную область. Стрелка меняет область для кнопки: все реплики, одна или эта и следующие. Изменения сохраняет основная кнопка |
| Посмотреть последствия | Рядом с кнопкой показано число изменений, в списке реплики отмечены «Имя изменится». В групповых действиях ручные имена защищены, пока явно не разрешена замена |
| Сохранить | Один обработчик сохраняет выбранную область. Переход к следующему голосу запускается отдельно |
| «Следующий голос» | Только навигация. Не сохраняет черновик и не обучает профиль |
| Выбрать другой голос или реплику | Черновик хранится по встрече и реплике. Возврат через любой вход показывает тот же черновик |
| «Отменить правку» | Сбрасывает черновик выбранной реплики. Редактор остаётся на этой реплике, фокус возвращается в поле имени |
| «К транскрипту» | Возвращает к выбранной реплике. Черновик сохраняется для возврата |
| Escape без открытого меню или модалки | Сбрасывает текущий черновик и возвращает в транскрипт к выбранной реплике |

Число групп Speaker N показывает количество групп голосов. Один человек может встречаться в нескольких группах.

## Обучение и управление людьми

Сохранился отдельный раздел «Голоса» в одной модалке настроек: поиск по 25 вымышленным людям, список и карточка человека. В узком окне список и детали показываются последовательно. Пять остальных разделов настроек сохранены.

При включённом обучении сохранение ручного назначения или исправления запускает автоматический подбор подходящих фрагментов. Можно исправить имена в старой встрече или разметить новую. Открытие, навигация, отмена и неизменённое автоматическое имя не добавляют образцы. Ручная правка одной реплики не делает остальные автоматические реплики обучающими.

«Сбросить обучение» сохраняет человека в списке, удаляет его образцы и отменяет устаревшие обновления профиля. Старые транскрипты и имена не меняются; другие люди не затронуты. Обучение начинается заново после сохранения ручного назначения или исправления имени. Удаление человека — отдельное подтверждаемое действие.

## Сценарии

- Основная встреча: знакомые голоса подписаны; два новых голоса остаются для ручного разбора.
- «Все знакомы»: результат без обязательной ручной работы.
- В едином редакторе выберите группу «Разные имена»: у каждой реплики видно своё имя и источник, форма соответствует выбранному фрагменту.
- Для проверки сброса: Настройки → Голоса → Анна → Сбросить обучение → подтвердить. Затем создайте новую запись с этим голосом: голос Анны потребует имени, остальные определятся автоматически. Старая встреча сохранит имена.
- Новая демонстрационная запись после остановки проходит маршрут обработки и получает имена по готовым профилям.

Дополнительные состояния: [неоднозначность и наложение](index.html?scenario=uncertain), [мало речи](index.html?scenario=little-speech), [аудио недоступно](index.html?scenario=audio-unavailable), [ошибка определения](index.html?scenario=recognition-error), [выключено](index.html?scenario=off), [нет модели](index.html?scenario=model), [устаревший профиль](index.html?scenario=stale), [ошибка обновления](index.html?scenario=update-error), [длинное имя](index.html?scenario=long-name).

## Файлы и проверки

Вход: index.html. Поведение: voice-identity.js. Оформление: voice-identity.css. Проверки общего редактора: voice-identity.test.cjs.

Проверки логики охватывают общий редактор и черновик, групповое применение с уже подписанной реплики, защиту ручных имён, область и изоляцию дорожек, одноимённых людей, сохранение человека при выключенном обучении.

Браузерные проверки тем, размеров, прокрутки, keyboard focus и Escape не выполнялись. Предыдущая попытка Chrome DevTools MCP была отклонена с MCP tool call requires approval, but approval policy is never; разрешение на другой браузер не получено. Unit tests не подтверждают UI/UAT.

Все встречи, люди и совпадения голосов синтетические; изменения до перезагрузки. Реального распознавания, аудио, обучения, календаря и загрузки моделей нет. Git baseline 7a83dd9 не сверялся.

## Компактные отметки в транскрипте

Значки робота и пера находятся внутри кнопки имени. Для последовательных реплик с тем же человеком, дорожкой и источником назначения имя показано один раз. У каждой реплики остаются таймкод и карандаш для редактирования текста. У реплик без повторённого имени говорящего можно изменить значком людей. Эти кнопки появляются при наведении на реплику или фокусе с клавиатуры. На сенсорном экране они видны сразу. У неподписанных реплик доступно явное действие «Назначить имя».
