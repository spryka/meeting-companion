# Визуальная приёмка голосовых профилей

Используй проверенный владельцем [снимок](reference/screenshot-2026-11-20T14-43-49-056Z.png) и [интерактивный макет](reference/index.html). [Карта](reference/voice-identity-map.md) описывает состояния. Контракты сохранения, обучения и отказов заданы в [дизайне](design.md) и specs этого change.

## Единый редактор

- «Имена участников» занимает правую область workspace. Вход из имени открывает выбранную реплику с областью «Только эта реплика». Вход из шапки открывает тот же редактор с областью группы. При возврате существующий черновик и выбранная пользователем область сохраняются.
- Над списком — «Все / Неопознанные» со счётчиками по сохранённым именам. При исчезновении текущей группы из фильтра выбрать следующую по правилу S06. При отсутствии подходящих групп показать пустое состояние.
- В списке видны имя, происхождение, дорожка и количество реплик. Смешанная группа показывает «Разные имена». Отсутствующий personID у части реплик с тем же именем сохраняет имя группы. У отдельной реплики показаны таймкод с воспроизведением, текст, отмеченное автоимя или причина отказа, одно поле поиска и раскрываемый список других реплик. Вся строка заголовка раскрывающейся секции кликабельна.
- Поле предзаполняется сохранённым именем. Поддержи одноимённых людей по personID и доступной подписи/контакту, отдельное происхождение календарного варианта.
- Для старого имени без профиля рядом с выбранной репликой доступно «Подтвердить имя для обучения». Кнопка использует только прослушиваемую реплику. Обычное «Применить» сохраняет правки с выбранной областью.
- До «Применить» видны область, число изменений, защита ручных имён и preview затронутых реплик. «Следующий голос» только навигирует. «Отменить правку» доступно при невалидном вводе. Escape в первую очередь закрывает меню или завершает ввод IME. Возврат в транскрипт фокусирует выбранную реплику.
- Автоимена и ручные имена имеют различимые компактные отметки. Одинаковые человек, дорожка и происхождение допускают свёртку повторной подписи. Кнопки каждой реплики доступны при наведении и с клавиатуры. У неизвестного голоса виден вход в редактор.

## Настройки

- «Голоса» — шестой раздел существующей модалки. На широком окне видны поиск, список и карточка, на узком — последовательные экраны. Сохранить блокировку фона, фокус и общие системные controls workspace.
- Показать первое включение, недоступную модель и явную подготовку, готовую базу, обучение и его ошибку. Ошибка обновления отдельно от готовности существующего профиля.
- Показать состояние рабочей сборки с готовым ручным обучением до калибровки. «Запоминать голоса» разрешает обучение с подготовленной моделью. Пока политика сопоставления недоступна, «Голоса» показывают «Автоимена станут доступны после калибровки.» Состояния с автоименами в макете показывают результат работы откалиброванной политики.
- Обучение запускает обычное сохранение нового ручного имени. Сброс обучения, удаление человека и удаление базы — отдельные подтверждения. Отмена возвращает фокус к инициатору. Персональный сброс сохраняет карточку и уже подписанные транскрипты.
- Если черновик остался на другой реплике, над транскриптом и редактором доступно «Вернуться к правке». Действие показывает реплику с сохранённым вводом, в том числе если её скрывал фильтр.

## Парные скриншоты

- Запустить собранное нативное приложение с синтетическими данными. Зафиксировать версию сборки, состояние, тему, размеры области окна в pt и масштаб. Сравнивать область окна с той же областью макета в одинаковом размере и состоянии.
- Приложить пары для светлого редактора с выбранным Speaker 1 из исходного снимка, фильтра с автоименами/отказами и раздела «Голоса». Проверить тёмную тему, узкое/низкое окно, длинные имена и прокрутку. Сохранять воспроизводимые параметры и различия.
- Нативно проверить оба входа, выбор областей, клавиатуру, VoiceOver, Cancel, возврат фокуса, Settings ownership и параллельные capture/voice job. Результаты приложить к 8.3 только после проверки этой сборки.
