# UI и реализация

## Context

Базовый master: `32de9bb`. Основной редизайн уже принят. Это только отображение обработки и переход к её подробностям. Дизайн продолжает текущие `ODColors`, системный шрифт и native controls. [HTML](reference/index.html) вспомогателен; правила ниже обязательны.

## Goals / Non-Goals

Показать место в процессе, общий маршрут и детали по запросу. Без ETA, общего процента времени, второй очереди, изменения моделей или экрана записи во время capture. Кнопки stop/mute записи не затрагивать.

## Decisions: точный UI

### Капсула обработки

Сохранить существующий округлый nonactivating NSPanel, фиксированную ширину около 420 pt, позицию/drag/Spaces. Слева текстовый блок, справа одна native text button «Подробнее»; поля 32 pt слева, 16 pt справа и 12 pt по вертикали, зазор 12 pt. Увеличенный левый отступ согласован обратной связью владельца: после удаления иконки тексту нужен воздух у скругления. После успешного завершения подпись кнопки «Открыть».

В текстовом блоке сверху название записи: system 13 pt semibold, одна строка с ellipsis, полный текст в accessibility/help. Под ним system 11 pt regular: `Этап 5 из 7`; на последнем: `Этап 7 из 7`. По обратной связи владельца отдельные «далее K» и «последний» убраны как избыточные. В очереди: `В очереди · 7 этапов`. Проценты, модель, дорожка и окна в капсуле отсутствуют.

Под подписью, через 8 pt, общий маршрут: M точек диаметром 8 pt, соединённых линиями 2 pt. Завершённые зелёные, текущая синяя с внешним кольцом, будущие контурные; при предупреждении квадрат с «!». Цвет дублируется доступным текстом состояния. Точки не кнопки, равные расстояния не означают равное время. Маршрут не заполняется по проценту текущей дорожки. При M=5 и M=7 наружные размеры капсулы одинаковы.

У капсулы НЕТ крестика, Hide/«Скрыть», close/minimize/zoom, закрытия через Escape/⌘W или меню. Это относится и к terminal-состоянию. Ошибка: `Не удалось обработать`; успех: `Готово` либо `Готово · есть замечание`. Исключены только пользовательские dismiss-команды: существующий автоматический terminal timeout и скрытие после принятого Open сохраняются с ownership guards R06.

### Экран выбранной записи

Использовать существующую правую область workspace, не новое окно/sheet. Сохранить библиотеку, header и стандартные системные кнопки окна. Сверху название записи и дата/длительность. Поля content 24 pt; ниже через 32 pt две колонки с зазором 32 pt: маршрут 200 pt, детали занимают остаток. Если деталям остаётся менее 280 pt, один столбец: текущие детали, затем маршрут; вертикальная прокрутка.

Маршрут вертикальный: шаг строки не менее 56 pt, узел 24 pt, линия 2 pt, отступ текста 12 pt. Название system 14 pt semibold; ниже status 12 pt. Завершено = зелёная галочка/«Завершено»; текущий = синий узел/«Сейчас»; будущий = контур/«Далее»; пропущенный = «!»/«Пропущено», с причиной. Ошибка не отмечается галочкой успеха.

Детали: `Этап N из M`, заголовок этапа 24 pt semibold, название модели, `Микрофон · дорожка 1 из 2` или `Системный звук · дорожка 2 из 2`. Для общего этапа дорожку не показывать. Одна полоса 4 pt, только для достоверного completed/total; рядом процент и единицы (`96 из 150 окон`, AEC в процентах кадров). total неизвестен или доступно только начало/конец: `Выполняется…`, без процента и без искусственно движущейся полосы. Предупреждения текстом ниже; fatal error с существующим допустимым retry. В продукт не переносить демонстрационные переключатели.

### Маршрут и данные

Порядок UI: Сборка аудио → Подавление эха [AEC] → Разделение голосов [Nemotron] → Поиск речи [Silero VAD] → Распознавание [GigaAM, включая назначение голосов словам] → Уточнение терминов [Parakeet, включая каскад] → Сохранение [микс плеера, объединение текста, публикация].

AEC/Parakeet выключены в принятой конфигурации job: исключить их до старта, M=5/6/7; не менять маршрут из-за текущих Settings. При retry использовать конфигурацию нового job. Включённый, но фактически пропущенный/сбойный необязательный этап остаётся в маршруте с причиной. Две дорожки не являются двумя станциями; этап завершён только после обеих. Возврат локального процента к нулю при переходе к другой дорожке допустим, поскольку её подпись меняется.

Один snapshot на job хранит план, состояния этапов и дорожек; App отображает его в двух местах. Progress не выполняет navigation, не активирует окно и не меняет выбранную пользователем другую запись. Для «Сборки аудио» события даёт существующая finalization; worker сообщает начало mix/merge/publication, UI объединяет их в «Сохранение». На загрузке модели текущий этап уже должен быть объявлен. Не рисовать 100% всего процесса до принятого успешного результата. Устаревшие события другого job игнорируются.

«Подробнее» показывает/активирует единственный workspace и выбирает запись этого job через существующий admission. Settings/несохранённый ввод не обходить: оставить капсулу и понятный feedback, не терять ввод. Повторный клик не создаёт окно/job. Красная системная кнопка закрывает только workspace; ⌘W при допустимом close делает то же. Повторное открытие восстанавливает актуальный snapshot. Отдельной кнопки «Скрыть окно» нет.

Цвета: переиспользовать ODColors. Светлая тема: ink #202733, muted #647084, accent #2666b5; тёмная: ink #f0f2f6, muted #a4adbc, accent #8ab9ff; green/warning/track брать из существующих tokens. Native keyboard focus, VoiceOver: имя записи, текущий этап и общее число этапов, предупреждения; обновления не объявлять на каждое окно ASR. Анимации обработки нет.

## Risks / Trade-offs

Число этапов не измеряет время. Неточная телеметрия → отсутствие процента. Существующий 60-секундный terminal timeout не превращать в таймер активной обработки.

## Migration Plan

Переиспользовать текущие hosts и guards, добавить snapshot/events, подключить оба UI. Записи не мигрировать. При откате UI не удалять записи/результаты.

## Open Questions

Продуктовых вопросов нет. Перед реализацией сверить revision и actual progress API; при дрейфе обновить техническую привязку, не менять этот UI-контракт молча.

## Дополнение при локальной beta-проверке

После закрытия workspace запрос загрузки инвалидируется. Показ окна через Settings сам по себе не открывает транскрипт. Явный выбор записи мышью или стрелками проходит через общий `selectLibraryRecording`: сохраняет modal/draft admission, выбирает canonical URL и возобновляет `requestWorkspaceOpen`. Arrow navigation не меняет видимую narrow library pane; повторный выбор того же URL тоже восстанавливает загрузку. Форматы и файлы записей не меняются. Локальная установка beta.33/build69 отдельно разрешена владельцем после реализации; публикация не запрошена.
