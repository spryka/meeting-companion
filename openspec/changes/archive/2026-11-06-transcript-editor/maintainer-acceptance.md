# Протокол приёмки сопровождающим с исключениями (Maintainer Acceptance Protocol)

Дата: 2026-11-01
Изменение: `transcript-editor`
Решение сопровождающего: **Принято с исключениями (`accepted-by-maintainer-with-exceptions`)**
Статус архивации: **Закрыто с явно снятыми остатками, 2026-11-06**; [новое решение владельца](../../../../docs/beta30-acceptance.md) заменяет прежний запрет автоматической архивации ниже.

---

## 1. Резюме решения сопровождающего

Сопровождающий проекта официально утвердил приёмку изменения `transcript-editor` со статусом **«принято с исключениями»** (`accepted-by-maintainer-with-exceptions`). Данное решение завершает работу над изменением без дальнейших циклов ремонта и без автоматической архивации в OpenSpec.

Основанием для приёмки является успешное подтверждение пользователем ключевого пользовательского пути на реальном Mac, при одновременной честной фиксации всех исключений, снятых проверок и известных рисков без фабрикации фиктивных результатов PASS.

---

## 2. Подтверждённый пользовательский сценарий (User Acceptance)

Пользователь выполнил общую ручную проверку базового сценария работы на установленной старой версии приложения (1.7.2/36) на реальном Mac и сообщил, что основные шаги соответствуют ранее запрошенному базовому сценарию («всё ОК»):
1. **Открытие**: открытие окна расшифровки из истории записей. (Отдельные свидетельства явной фокусировки уже существующего окна при повторном открытии не фиксировались).
2. **Воспроизведение**: запуск и воспроизведение аудио. (Отдельные свидетельства перехода по таймкодам `[HH:MM:SS]`, автоскролла или кнопки возврата к следованию не фиксировались).
3. **Редактирование текста**: редактирование текста реплики и сохранение изменений.
4. **Назначение имён**: назначение имени говорящему.
5. **Сохранение и повторное открытие (Reopen)**: сохранение изменений и их отображение после закрытия и повторного открытия окна.
6. **Отмена действия (Undo)**: функциональная работа кнопки отмены Undo на установленной версии (с исходной надписью «Отменить») подтверждена ДО переименования кнопки. Последующее переименование кнопки в тулбаре на «Отменить изменение» (и доступность «Отменить последнее изменение») выполнено в исходном коде, собрано и верифицировано компилятором и тестами/UI harness, но НЕ проходило повторного физического UAT на реальном Mac. Кнопки отмены черновиков внутри форм и строк оставлены без изменений («Отмена»).
7. **Экспорт**: сохранение расшифровки в файл.
8. **Предупреждения**: наблюдаемое предупреждение признано некритичным.

**Границы подтверждения**: пользователь подтвердил только общий базовый сценарий в целом («всё ОК»). Детальные гранулярные шаги (фокусировка существующего окна, клики по таймкодам, поведение кнопки возврата к следованию), а также проверки VoiceOver, цветовых тем оформления (Light/Dark), слуховой оценки эхоподавления AEC и 8-часового сценария не исследовались отдельно, отдельных свидетельств не имеют и не заявляются как проверенные.

## 3. Исключения, снятые требования и оценка рисков (Waivers & Exclusions)

Все невыполненные проверки сохранены в честном статусе с неснятыми чекбоксами (`[ ]`):

1. **Задача 5.1 — Сбой скрипта диагностики (`check-diagnostics.swift`)**:
   - Наблюдаемое поведение: скрипт `scripts/check-diagnostics.swift` аварийно завершается с кодом 133 (SIGTRAP на строке 59) из-за несовпадения текстового ожидания в тесте (`"Проверить звук"`) с фактическим кодом `RecorderDiagnostics.swift:55` (`"Не проверен"`).
   - Решение сопровождающего: данный сбой остаётся подтверждённым фактическим несовпадением утверждений старого теста. Сопровождающий официально **исключает** данную диагностику из приёмки текущего изменения как несвязанную стороннюю проверку, не требуя её починки и не заявляя её прохождение на оборудовании. Повторный запуск скрипта исключён. Чекбокс `- [ ] 5.1` остаётся неснятым.

2. **Задача 5.2 — Ручной UAT на Mac**:
   - Базовый сценарий подтверждён пользователем (см. раздел 2).
   - Непроверенные пункты (навигация через VoiceOver, проверка контраста в светлой и тёмной темах, слуховой контроль подавления эха AEC при различных конфигурациях дорожек) официально **отложены и сняты (waived)** сопровождающим для данного изменения. Чекбокс `- [ ] 5.2` остаётся неснятым.

3. **Задача 5.3b — Восьмичасовой UAT**:
   - Проверка **НЕ проводилась**.
   - Решение сопровождающего и пользователя: требование 8-часового непрерывного UAT **снято (waived)** для текущего изменения как осознанный риск. Пользователь принял решение перенести возможное выявление дефектов длительной работы на этап последующих bugfix-релизов при возникновении необходимости. Фабрикация результатов замера или ложный PASS категорически исключены; чекбокс `- [ ] 5.3b` остаётся неснятым.

4. **Задача 5.4 — Итоговая сверка и приёмка**:
   - Задача 5.4 закрыта (`[x]`) официальной приёмкой сопровождающего с зафиксированными исключениями (maintainer acceptance with documented waivers) на основании координаторского подтверждения PASS (не являясь самоодобрением билдера). Непроведённые проверки 5.1, 5.2, 5.3b сохранены неснятыми (`[ ]`) как неблокирующие по решению пользователя и сопровождающего.

5. **Программный тестовый пробел (Parakeet retry GAP)**:
   - Отсутствие отдельного теста с варьированием параметров Parakeet между последовательными прогонами retry для доказательства неизменности `baselineWords` и `warnings` на уровне Python принято сопровождающим как известный допустимый риск.
