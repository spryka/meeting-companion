# Компактное напоминание о встрече

## Why

Существующее напоминание визуально выбивается из workspace: большая пустая панель и слабая иерархия действий. Выбор из множества встреч не должен увеличивать само напоминание.

## What Changes

- Перенести согласованную композицию HTML в native reminder: название и время, заметное основное действие, вторичное «Пропустить».
- Два состояния: новая запись и переход с уже активной записи; показать текущую запись и последствия перехода.
- Отдельный ограниченный по высоте список с прокруткой, без поиска; сохранить «Без встречи» и исключение текущей записываемой встречи.
- Сохранить shared startMeeting/stop/start, session guards, calendar acknowledgement и auto-dismiss; не переносить демологику HTML.
- При ошибке показать понятную причину и завершить попытку. Повтор — только через новый ручной вход с актуальными проверками; без автоматических повторов, обходных путей и восстановления workflow.

## Capabilities

### New Capabilities

- `meeting-reminder-ui`: внешний вид напоминания, выбор встречи и действия в двух состояниях.

### Modified Capabilities

Нет. Контракты recording-overlay R01/R02/R05/R06/R07 сохраняются; новые UI-детали добавлены отдельной capability.

## Impact

`RecorderAppDelegate.swift` (showReminder, MeetingReminderView), существующие UI tokens и необходимые presentation helpers. Общий `AppMain.swift.startMeeting` переиспользуется с минимальной доработкой актуальности встречи, session/modal/admission checks до stop и перед новым capture после ожиданий, а также передачи реального отказа/ошибки в видимый UI. Допустимы необходимые проверки на общей границе старта и синтетические test seams; отдельный lifecycle не создаётся. Тесты reminder/calendar/admission и native UI. Без новых зависимостей, storage/schema, pipeline или изменения календарного расписания напоминаний.
