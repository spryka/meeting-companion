# ADR Review Manifest

## Review Summary

Сверка для этого SDD выполнена по архитектурным решениям из доступного в проекте снимка Meeting Companion и описанию голосовых профилей в соседнем OpenSpec change. Изменение относится к представлению: нативные кнопки вызывают существующие операции текущего документа. На этапе реализации исполнитель сверяет набор действующих ADR в целевой ревизии.

## In-Force ADRs Reviewed

- ADR-0001 и уточняющий его ADR-0004 задают сохранение правок относительно текущего результата. Контекстное действие адресует исходную реплику по её ID в этом результате.
- ADR-0003 относит сценарии приложения к существующим сервисам. Hover, фокус и вариант компоновки принадлежат представлению.
- ADR-0006 помещает просмотр транскрипта в рабочее окно. Сохраняются общий сеанс просмотра и действующие точки входа в правку. Уточнение ADR-0007 относится к настройкам.
- ADR-0002 и ADR-0005 в локальном снимке касаются worker и хранения записи. Для этого изменения достаточно данных, которые уже читает экран. Условия обучения по сохранённому имени описаны в [SDD каталога голосов](../../../voice-settings-directory-handoff/openspec/changes/voice-settings-directory/adr.md); открытие контекстной команды само по себе не запускает обучение.

## New Durable ADRs Created

Новых архитектурных решений для репозитория не требуется. Компоновка реплик и показ действий описаны в [design.md](design.md).
