# ADR-0010: Подтверждение сохранённого имени на реплике

Status: proposed
Date: 2026-11-21
Extends: ADR-0009 — событие обучения для ранее сохранённого имени.

## Context

В старых расшифровках уже есть ручные имена без привязки к голосовому профилю. Пользователь прослушивает конкретную реплику в редакторе и подтверждает её имя одним действием.

## Decision

При включённом запоминании «Подтвердить имя для обучения» сохраняет привязку только выбранной реплики через обычную транзакцию edits. Действие доступно для ручного имени или старого имени без происхождения, пока у реплики отсутствует `personID`. Пользователь подтверждает личность по услышанной речи. При тёзках выбор профиля остаётся явным. Машинное имя и уже связанное назначение этим действием не обучаются.

Качество аудио проверяется после записи события. Ручное обучение использует подготовленную локальную модель. Автоимена при обработке нового результата дополнительно требуют откалиброванной политики сопоставления. Отзыв ранее сохранённых эталонов использует действующий механизм.
